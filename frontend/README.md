# Career Copilot — Frontend

React + TypeScript SPA (Vite, Tailwind v4) for Career Copilot. See the [root README](../README.md)
for what the project is, the architecture diagram, and the quickstart. Design system and component
conventions are in [`DESIGN.md`](./DESIGN.md).

```bash
cp .env.example .env
npm install
npm run dev     # http://localhost:5173
npm run lint
npm run build   # tsc -b && vite build
```
